# OCWORLD 30-character collection

30 new original transparent PNG templates; 10 each in Sevnzel graphic-toy, Aokizy graphic concept, and Xiaozhi-inspired pixel adventure directions. Existing saved characters and earlier templates remain intact. Templates are opt-in: preview, create, confirm birth. Each saved character receives its own stable characterId.

The homepage keeps Xiaozhi as its hero and ZEALWISH layout. Default library filter displays this release's 30 templates; direction filters show ten each. Earlier templates remain in a separate filter. Chinese is the default; all new names and concepts have English versions.

These are pre-generated built-in image-tool assets. Runtime API generation is separate and depends on the configured image provider. No credentials are embedded in the static site.
